# Kite

Design in [Kite](https://kite.new) from your agent: banners, social posts, ads, logos, landing pages and app screens, drawn into a design file your team edits and comments on.

## What it adds

- **MCP server `kite`** — Kite's hosted server at `https://kite.new/api/mcp` (Streamable HTTP, OAuth 2.1 with PKCE). Tools to make files, draw and edit layers, use design-system tokens, place components, render previews and read and answer comments.
- **Skill `kite`** — how to design well in Kite: plan tokens and components first, draw in small pieces, edit rather than redraw, check fonts, hand back the file's link.

## Setup

1. Install the plugin.
2. Connect the `kite` server. Kite opens in the browser: sign in and click **Allow**.
3. Ask: "Design a launch banner in Kite and give me the link."

No API key or configuration is needed. To disconnect, remove the agent under Kite's settings → Agents → Connected apps.
